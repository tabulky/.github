# Tabulky.ART

**Organizace dat ve strukturované podobě**

## O projektu

Tabulky.ART je projekt, který se věnuje důležitosti organizace dat ve strukturované podobě. Vychází se z **E-R modelu** (Entity-Relationship model) a pravidel formálních norem, které jsou dobrým předpokladem pro efektivní získávání dat pro další zpracování.

## Filozofie

Nikdy není dopředu jasné, jak bude vhodné navrhnout databázi. Odpovědi na tato témata bude možné hledat v této organizaci.
